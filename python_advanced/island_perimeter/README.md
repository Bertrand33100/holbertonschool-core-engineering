# Périmètre d’une île

`0-island_perimeter.py` définit `island_perimeter(grid)`, qui renvoie le
périmètre de l’île représentée dans une grille rectangulaire de `0` (eau) et
de `1` (terre).

La fonction ajoute quatre côtés pour chaque case terrestre et en soustrait
deux pour chaque côté partagé par des cases terrestres adjacentes. Elle
n’utilise aucun module.
